Prise en main du SDR

Cours

1. Architecture d'un SDR

Contrairement à une radio classique figée dans ses composants analogiques, un SDR numérise le signal radio le plus tôt possible : antenne → étage RF → convertisseur analogique-numérique (ADC) → tout le reste (filtrage, démodulation, affichage) se fait en logiciel. C'est ce qui rend le NESDR capable de couvrir 100 kHz à 1,75 GHz avec le même matériel.

2. Pourquoi un up-converter ?

Le tuner R820T2 de la clé NESDR ne descend bien en pratique qu'à partir d'environ 24 MHz. Or le RFID LF (125 kHz) et une partie du HF se situent en-dessous. Le Ham It Up Nano résout ce problème en mélangeant le signal reçu avec un oscillateur local fixe (souvent 125 MHz) : un signal à 125 kHz ressort alors vers 125,125 MHz, une zone que le R820T2 reçoit très bien. Le logiciel SDR doit ensuite soustraire ce décalage pour réafficher la fréquence réelle.

3. Rôle du TCXO

Un oscillateur à quartz standard dérive avec la température. Le TCXO (Temperature Compensated Crystal Oscillator) compense cette dérive, ce qui est indispensable ici : toute erreur de fréquence de l'oscillateur local de l'up-converter se répercute directement sur la fréquence affichée.

4. Logiciels SDR

SDR# (Windows), GQRX (Linux/Mac) et SDR++ (multiplateforme) permettent tous d'afficher le spectre et le waterfall, de régler le gain et d'appliquer un décalage de fréquence pour corriger l'up-conversion.

Atelier

Objectif : assembler et configurer la chaîne SDR complète.

Matériel : NESDR Smart V5, Ham It Up Nano, adaptateurs SMA, câble micro-USB, antenne adaptée, PC.

  1. Installer le logiciel SDR choisi (SDR#, GQRX ou SDR++).
  2. Assembler la chaîne : antenne → Ham It Up Nano (alimenté en micro-USB) → adaptateur SMA-SMA → clé NESDR → port USB du PC.
  3. Sélectionner le périphérique NESDR dans le logiciel.
  4. Configurer le décalage de fréquence correspondant à l'oscillateur local du Ham It Up Nano (vérifier la valeur exacte dans sa documentation).
  5. Vérifier qu'un signal connu apparaît correctement décalé (approfondi en séance 4).
  6. Schématiser le câblage réalisé.
Livrable : schéma de câblage annoté du poste SDR complet + capture d'écran du logiciel SDR configuré avec le bon décalage de fréquence
